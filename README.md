# 🚀 Smart Tech Pulse

AI-powered personalized news aggregator using RAG (Retrieval-Augmented Generation).

## 🔥 Features
- Real-time news fetching (RSS feeds)
- Semantic search using embeddings (ChromaDB)
- LLM summaries using Groq + Llama
- Personalized content based on user interests

## 🛠 Tech Stack
- FastAPI
- ChromaDB
- LangChain
- Groq (Llama 3)
- Sentence Transformers

## 📊 Architecture
RAG Pipeline:
Fetch → Embed → Store → Retrieve → Summarize
